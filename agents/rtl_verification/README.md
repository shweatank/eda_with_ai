
# RTL Verification Platform

A complete EDA/CAD RTL verification platform with ALL gates (AND, OR, NOT, NAND, NOR, XOR, XNOR, MUX, Adder) using **Cocotb** testbenches and **FastAPI** backend.


**ALL Digital Logic Gates**: AND, OR, NOT, NAND, NOR, XOR, XNOR
**RTL Simulation** using Icarus Verilog
**Testbenches** using Cocotb (Python)
**REST API** for simulation control
**Waveform Generation** (FST format)
**GTKWave Integration** for waveform viewing
**Web-based Interface** (optional)
